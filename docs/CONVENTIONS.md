# Engineering Conventions

- Keep TypeScript strictness enabled.
- Prefer semantic HTML and accessible controls.
- Use descriptive component and file names.
- Keep components focused and reusable.
- Avoid `any`; justify unavoidable use.
- Centralize design tokens.
- Keep secrets in environment variables; never commit `.env` files.
- Validate external inputs at trust boundaries.
- Do not fabricate product content or business policies.
- Record dependency and architecture decisions in `DECISIONS.md`.
- Apply consistent formatting and linting using tooling selected during setup.
